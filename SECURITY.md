# Security reports

Report sensitive findings privately through [GitHub vulnerability reporting](https://github.com/q133ss/cryptoledger/security/advisories/new). Include the affected release, the invariant involved and the observed behavior. Use synthetic accounts and omit credentials or customer information.

The hosted repository contains a reference implementation. Its Compose credentials and generated development CA are for local demonstration. See [the threat model](docs/threat-model.md) for the trust assumptions.
